## Introduction

This application allows users to manage research-related data in a structured and secure way. It is designed to support workflows for creating, registering, and organizing different types of entities within groups and projects.

With this app, you can:

- Register custom entities such as persons or other research-relevant objects  
- Assign and manage identifiers and metadata for these entities  
- Create and manage pseudonyms to pseudonymize sensitive data  
- Organize entities within groups and projects, and manage access through permissions  

This user guide explains the main features of the application step by step and helps you understand how to perform common tasks within the system.
