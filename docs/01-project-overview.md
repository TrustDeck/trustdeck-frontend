## Project Overview

### Overview

After logging in, you are directed to the **Project Overview** page. This is the entry point of the application and provides access to all projects you have permission to view or manage.

Each project represents a separate workspace in which entities, pseudonyms, and groups are managed independently.

---

### Existing Projects

If you already have access to one or more projects, they are displayed in a list on this page.

From here you can:
- Open a project by clicking on it
- Continue working in an existing workspace

---

### No Projects Available

If no projects are shown, you currently do not have access to any projects.

In this case, you either need to ask a colleague to add you to an existing project, or you need to assign yourself global permissions so that you can create a project. 

---

### Next Step

After selecting or creating a project, you will enter the project workspace where you can start managing entities, pseudonyms, and groups.
