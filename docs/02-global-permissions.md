## Global Permissions

### Overview

Global permissions control whether a user is allowed to access or manage projects within the system. Before you can create or work with projects, you may need to assign yourself the appropriate global permissions.

These permissions are user-specific and are required to initialize access to the system’s project structure.

---

### When to use Global Permissions

You need to set global permissions if:

- You have just logged in for the first time  
- You need to create a new project

---

### Assigning Global Permissions

To assign global permissions to your user:

1. Click on the **Global Permissions** button from the Project Overview page  
2. Search for your user by name  
3. Select your user from the search results  
4. Choose the appropriate permissions for your role  
5. Confirm and save your selection  

---

### After assigning permissions

Once global permissions are assigned:

- You will be able to view existing projects (if any exist)
- You can create new projects
