## Global Permissions

### Overview

Global permissions control whether a user is allowed to create projects, groups, and entity types or to work with base types. They are not tied to a single project.

Only users who hold the permission to manage global permissions can assign them, and they can only assign permissions they hold themselves. On a fresh installation, the operator sets up the first administrator; this administrator then hands out global permissions to other users.

---

### When to use Global Permissions

You need global permissions if:

- You want to create a new project, group, or entity type
- You want to work with base types

Ask an administrator for them. You don't need global permissions to see the projects you have access to.

---

### Assigning Global Permissions

To assign global permissions to another user:

1. Click on the **Global Permissions** button from the Project Overview page  
2. Search for the user by name  
3. Select the user from the search results  
4. Choose the appropriate permissions; permissions you don't hold yourself can't be selected  
5. Confirm and save your selection  

---

### After assigning permissions

Once global permissions are assigned, the user can, for example:

- Create new projects and becomes their manager
- Create groups and entity types
