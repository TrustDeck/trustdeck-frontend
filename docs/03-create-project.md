## Create Project

### Overview

A project is the main workspace in which entities, pseudonyms, and groups are managed. Each project is independent and has its own data scope and access permissions.

Creating a project is required before you can start working in the system.

---

### Prerequisites

Before you can create a project, you must:

- Have been assigned the global permissions **domain:create**, **domain:create-complete**, **domain:list-all**, **project:create**, **project:list-all**, and **base-type:create**
- Be able to access the **Project Overview** page

If you do not meet these requirements, please refer to the Global Permissions section.

---

### Creating a New Project

To create a new project:

1. Navigate to the **Project Overview** page  
2. Click on the **New Project** button  
3. Enter the required project information
4. Confirm by clicking **Create project**

---

### After Creation

Once the project is created:

- You will be redirected to the project workspace's Group Mangement page
- It will appear in your Project Overview list  
- You can click on it to enter the project workspace  
- You can start managing entities, pseudonyms, and groups within the project  

---

### Troubleshooting

If you cannot create a project:

- Check that you have assigned global permissions correctly  
- Ensure all required fields are filled in  
- Verify that you have sufficient rights to create projects
