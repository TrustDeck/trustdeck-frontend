## Project Permissions

### Overview

In **Project Settings**, users can manage access to a specific project by assigning permissions to other users.

This allows fine-grained control over who can view, create, edit, or delete data within the project.

---

### Managing Project Access

To grant access to a project:

1. Navigate to **Project Settings**  
3. Search for a user by name in the permissions section 
4. Select the user from the search results  
5. Assign the appropriate permissions  

---

### Permission Levels

Permissions can be configured at a granular level by selecting checkboxes

---

### Group-Level Permissions

Permissions are not only assigned at the project level, but can also be configured per group.

For each group within a project, you can define:

- Which users have access  
- What actions they are allowed to perform

This enables fine-grained control over data access and ensures that users only interact with the parts of the project relevant to their role.

---

### Example

A user may:
- Have **read-only access** to most groups  
- Be allowed to **create and update entities** in a specific group  
- Have **no access** to sensitive groups
